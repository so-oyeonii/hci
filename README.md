## 단축키

| 키 | 동작 |
| --- | --- |
| `←` `→` `Space` | 슬라이드 이동 |
| `N` | 발표자 대본 |
| `F` | 전체 화면 |
| `L` / `Esc` | 화면 정리(발표 도구 숨김) ↔ 도구 표시 |
| `P` | 인쇄 (대본 포함) |

화면 정리 상태가 기본값이라 열자마자 슬라이드만 보입니다. 발표 도구(타이머·대본·페이지 이동)가 필요하면 `L`을 누르세요.
